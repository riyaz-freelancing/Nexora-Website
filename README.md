# NexOra • Web & Digital Services

> **Click. Connect. Convert.**  
> Official website for **NexOra**, a premier digital agency delivering high-performance web development, mobile apps, custom UI/UX design, and digital marketing solutions.

---

## ✨ Key Features

- **Cinematic Video Hero Showcase:** Seamless, edge-to-edge ambient video experience with interactive audio toggling and smooth scroll cues.
- **Modern Brand Identity:** Complete NexOra visual branding featuring dark/light aesthetic, gradient typography, and custom high-resolution logo.
- **Dynamic Service Catalog:** Interactive service cards with tabbed categories (Web, App, UI/UX, SEO & Digital Marketing).
- **Curated Combo Packages:** Strategic service bundles designed for startups, SMEs, and enterprise growth.
- **Live ₹ INR Price Calculator:** Interactive quote estimator providing real-time budget transparency for client scopes.
- **Interactive Modals:** Instant consultation request modal, custom quote forms, and legal policy overlays (Privacy & Terms).
- **WhatsApp & Call Quick-Connect:** Floating quick-access communication widgets for immediate client onboarding.
- **Founder & Leadership Spotlight:** Highlighting co-founders across Client Relations, Full-Stack Architecture, and Marketing.
- **Client Testimonials:** Real client success stories with rating benchmarks.
- **Fully Responsive & Accessible:** Fluid cross-device layout optimized for mobile, tablet, and desktop screens.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/riyaz-freelancing/innaya-website.git

# Navigate to project directory
cd innaya-website

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### Production Build

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
